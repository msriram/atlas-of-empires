# Repository instructions

Before changing any site feature, map data, renderer, timeline, or deployment behavior, read [docs/CORE_REQUIREMENTS.md](docs/CORE_REQUIREMENTS.md). Treat its geographic alignment, independent and continuous empire change, and performance checks as acceptance criteria. Run the relevant automated checks and manually inspect the specified historical years and both projections for map changes. Update the requirements document when a product requirement is clarified; do not silently weaken it to accommodate an implementation.
